# CryoViking Musichook

## How do I install these formulae?

`brew install cryoviking/musichook/<formula>`

Or `brew tap cryoviking/musichook` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cryoviking/musichook"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
